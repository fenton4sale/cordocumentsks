# COR Cover-up Document Archive

Static website for GitHub Pages, Netlify, Cloudflare Pages, or any static host.

## How to upload to GitHub

1. Create a new GitHub repository.
2. Upload **all files and folders** from this package, including:
   - `index.html`
   - `assets/`
   - `documents/`
3. Commit the files.
4. In GitHub, go to **Settings > Pages** and publish from the main branch.

## How to deploy to Netlify from GitHub

1. Push this folder to GitHub.
2. In Netlify, choose **Add new site > Import an existing project**.
3. Connect the GitHub repository.
4. For this static site:
   - Build command: leave blank
   - Publish directory: `/` or leave blank depending on the Netlify screen
5. Deploy.

## Documents

The trial transcript PDFs have been combined into Day 1, Day 2, and Day 3 PDFs. Other court filings remain separate PDFs.
